Argumentative Enthymeme Detection & Reconstruction

Interactive Architecture Specification & Pipeline Dashboard

Project Motivation

Enthymemes are arguments containing missing or unstated logical premises left implicit by the speaker. This project implements an end-to-end NLP workflow to automatically isolate these gaps, detect implicit constraints, and reconstruct explicit argumentative bridges using deep learning auto-encoders.

Core Highlights

  • Detection Layer: Employs structured heuristics to map syntax abnormalities where logical links vanish.
  • Generative Core: Built using a fine-tuned fine-grained BART architecture configured to generate missing underlying structural assertions.
